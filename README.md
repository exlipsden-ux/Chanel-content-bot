# 🌟 Channel-content-bot

Telegram-бот с системой рефералов, обязательной подпиской на каналы, внутренним балансом (звёзды), промокодами и заявками на вывод средств.

## Возможности

**Для пользователей:**
- Реферальная система с начислением звёзд
- Обязательная подписка на спонсорские каналы/боты
- Личный профиль с балансом и статистикой
- Топ-10 лидеров по приглашениям
- Активация промокодов
- Заявки на вывод (15⭐, 25⭐, 50⭐)

**Для администратора:**
- Защищённая админ-панель (команда `/s` + пароль)
- Управление спонсорами (добавление/удаление)
- Рассылка сообщений всем пользователям
- Создание промокодов с лимитами
- Настройка награды за рефералов
- Модерация заявок на вывод через админ-канал

## Установка

```bash
pip install pyTelegramBotAPI
```

## Настройка

Откройте файл и заполните константы:

```python
TOKEN = "YOUR_BOT_TOKEN"
ADMIN_IDS = [123456789]
CHANNEL_ID = -1001234567890
ADMIN_PASSWORD = "your_password"
```

**Требования:**
- Бот должен быть администратором в `CHANNEL_ID`
- Бот должен быть администратором во всех спонсорских каналах

## Запуск

```bash
python stars_bot.py
```

## Структура БД

SQLite база `db.db` с таблицами:
- `users` — пользователи (баланс, рефералы, статистика)
- `sponsors` — обязательные каналы
- `promo_codes` — промокоды
- `withdrawals` — заявки на вывод
- `settings` — настройки (награда за реферала)

## Зависимости

- Python 3.x
- pyTelegramBotAPI
